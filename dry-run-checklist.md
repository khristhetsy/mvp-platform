# iCFO Virtual Private Equity Expo — Dry Run Checklist

**Sandbox event:** DRY RUN — _[date]_ (a Duplicate of the live event, visibility = Members only / Draft)
**Rehearsal time:** _[same time of day as the real event]_ · **Timezone:** _[e.g. America/Los_Angeles — PDT]_
**Director (runs the Manage screen):** _[name]_

> Rehearse on the **duplicated** event, never the live one. Aim to run it at the same time of day a few days out to catch timezone, link-expiry, and A/V issues.

---

## 1. Roles (assign before you start)

| Role | Person | Notes |
|------|--------|-------|
| Director / producer | | Watches Manage, cues go-live, handles issues |
| Host & moderator | | Talk Show host, welcomes attendees |
| Keynote speaker | | Auditorium |
| Panelists ×4 | | Talk Show guest roster |
| Featured founder (CEO) | | VIP Room / Founder Showcase |
| Test attendees ×2–3 | | Join on **different devices/browsers** |

---

## 2. Setup (do once, before the team joins)

- [ ] Duplicated the live event → renamed "DRY RUN — [date]"
- [ ] Visibility set to **Members only** or left as **Draft**
- [ ] Event **date/time + timezone** correct on the public page ("Add to calendar" lands right)
- [ ] Sessions present and in the right **running order** (drag to reorder)
- [ ] Each session's **live link** added and opens
- [ ] Talk Show **Guest Roster** pre-loaded (Host, CEO, Panelists 1–4)
- [ ] Sponsors / banners showing correctly in the lobby

---

## 3. Individual tech check (each presenter, 5 min each — do BEFORE the full run)

- [ ] Presenter can reach the event and **Enter lobby**
- [ ] Opens their session **live link**; camera + mic work
- [ ] **Screen share** works (slides / demo)
- [ ] Audio levels good, no echo; lighting acceptable
- [ ] Knows how to **Open live link** and **End session**
- [ ] Backup: presenter has the link saved separately in case the tab closes

---

## 4. Full run-of-show (real time, everyone in)

| Time | Segment | Owner | Actions to verify |
|------|---------|-------|-------------------|
| T-15 | Doors open / Lobby | Director | Attendees register → Enter lobby; presence count rises; booths/hotspots clickable |
| T-0 | Welcome | Host | Lobby ticker + welcome; wave/greeting works between attendees |
| +2 | Keynote (Auditorium) | Director → Speaker | **Go live** on Main Stage; attendees see stream; end cleanly |
| +20 | Talk Show — "Inside the Investor's Mind" | Host | **Bring on** each panelist from roster; camera tiles appear; remove/re-add works |
| +40 | Workshops (Exhibitors / Community) | Owners | Sessions go live; switching rooms works |
| +55 | Founder Showcase (VIP Room) | CEO | HealthTrack session live; sector track shows |
| +70 | Networking + Expo Hall | All | Lounge/booths reachable; sponsor pages load |
| +85 | Close | Host | End sessions; thank-yous; on-demand/recording note |

---

## 5. Attendee-experience checks (from the test attendees' side)

- [ ] Presence: their avatar shows; hover shows name; count is accurate
- [ ] Lobby navigation works on both desktop and mobile
- [ ] Live poll appears and records a vote
- [ ] Timezone shows correctly for an attendee in another zone
- [ ] Chat / wave / "Say hi" reaches the right person
- [ ] Leaderboard updates

---

## 6. Failure drills (practice these — they happen live)

- [ ] Speaker's live link dies → **End session** and relaunch with a fresh link
- [ ] Disruptive attendee → **mute / move / remove** from the control screen
- [ ] Host hand-off → second host can take over moderation
- [ ] Stream lag → fallback message / switch to backup link

---

## 7. Debrief (right after)

- [ ] Log every issue with who/what/fix
- [ ] Confirm the fixes needed on the **live** event (apply there, not the sandbox)
- [ ] Decide final running order and confirm all live links for event day
- [ ] Archive or delete the DRY RUN copy when done
