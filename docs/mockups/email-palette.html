The palette

Five hues, and three of them are near-misses of colours the platform already defines. Almost-matching reads worse than clashing, because the eye can’t decide whether it’s deliberate.

Teal, indigo and blue sitting side by side in one list is the thing that reads as cheap. And --gold in globals.css holds #2E78F5 — a blue — which is how a second blue got into circulation in the first place.

Worth knowing

This drops teal from the email. It is a real brand colour (--teal #0f766e) and it is used elsewhere in the product, so this is a decision rather than a correction: I’m saying a four-item agenda isn’t where a second hue earns its place. If you want teal kept as the keynote marker, it should be #0f766e — the token — not #0D9488.

--gold holds a blue. Renaming it touches everything that reads it, so this mockup leaves it alone and simply stops the email from using it. Worth fixing separately before it spreads further.

Accents are stored per session type in SESSION_ACCENT, which the booklet reads too. Changing the map changes both — which is right, but it means the booklet’s colours move at the same time.
