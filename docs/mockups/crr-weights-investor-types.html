These are different axes, and only one can key the four columns. Stage is a property of the company; investor type is a property of the reader. A family office invests at every stage, so it is not a substitute for “seed”. Doing both properly would be sixteen profiles, which nobody can maintain.

Note the current names already lean your way. angel is an investor type wearing a stage label, and its weighting — Team 30, Narrative 30 — is an angel’s priorities, not a pre-seed company’s. The tab has been half-way to what you described from the start. Yesterday we renamed it “Pre-seed” and wired stage → profile, which pushed it the other way.
