Metric tile — one design, every dashboard

The row layout's content, kept as a tile. Same component across founder, investor and admin.

The anatomy

  • Ring left, number right — the ring gives scale, the number gives the value. A count with no ceiling gets a dashed ring instead of a fake arc.
  • A footer line that says something. This is the part the old tiles didn't have room for: the denominator, and the one fact that changes what you'd do.
  • Drill arrow top-right, so the whole tile stays clickable without a button competing for space.
  • One component. MetricCard already takes ring; this adds flag for the coloured footer line. Every dashboard using MetricGrid picks it up.

One tile, one component. MetricCard already carries ring after today's change; this adds a flag prop for the coloured footer line and moves the drill affordance to a corner arrow. Every dashboard on MetricGrid — admin company workspace, admin analytics, insights, learning, SPV KPIs, founder dashboard and optimise, investor analytics and portfolio — inherits it.

The footer is the actual upgrade. "14" tells you nothing; "14 open of 18 · 4 high priority · oldest open 46 days" tells you whether to act today. Same for the empty states: instead of a bare 0, the investor tile says what to do to stop it being 0.

Tile height goes 112px → 146px to fit the footer. Four across still fits a 1280px screen; the grid stays auto-fit minmax(232px, 1fr) so it reflows to 2-up on a laptop and 1-up on mobile.
