The single point of failure

Everything hangs on book/route.ts:99. It reads an fs_session cookie, and only if it finds one calls handoffFitSession — the only code anywhere that writes lead_source from a campaign tag. The cookie is set by /fit and nothing else. So the question “was this meeting from social?” is really “did this person go through /fit in this browser first?” For your meetings, the answer is no.

Precedence — what wins when two signals disagree

Order of trust

first match wins · a lower row never overwrites a higher one
1 /fit session keep The person walked the funnel. You know the campaign, the answers and the intent. Always wins, even if the scheduler link also carried a tag. Highest
2 Tagged scheduler link They clicked a link you posted. Real click, real campaign — just no funnel behind it. High
3 Site-wide source cookie They arrived from a tagged link at some point in the window and booked later. Same evidence as 2, further from the booking in time. High
4 “How did you hear” Self-reported. Fills in where 1–3 saw nothing; never overwrites them. Flagged as self-reported on the row so you can discount it. Medium
5 Staff set it manually You sat in the meeting. Overrides everything, because a human decided — and the row records who and when. Manual
6 Nothing Stays Unattributed. Shown in the count, never folded into zero. None

Rows 1–3 are first-touch: once a booking has a source it is not replaced by a later signal of the same or lower rank. This matches what /fit already does (if (!overrides.lead_source)), so the platform keeps one rule instead of two. Row 5 is the deliberate exception — a person overriding a machine.

Unattributed shown, not hidden.
The unattributed count stays visible. Once capture works there will still be meetings nothing saw — a conference handshake, a referral. Folding those into zero is how the tile lied in the first place. Showing “5 unattributed” beside the number keeps it honest and tells you how much of your funnel is dark.

Self-reported is marked as such. A tag from an actual click and an answer to “how did you hear” are not the same quality of evidence. C should never overwrite A or B — it fills in where they saw nothing, and the row says which one it was.

Settled by keeping path 1. Choosing to preserve the /fit funnel settles the first-touch question with it: that code already refuses to overwrite an existing lead_source, so first-touch becomes the rule everywhere by default rather than by a second decision. The cost is real and worth naming — the post that first found someone gets the credit, not the one that finally brought them back to book.
