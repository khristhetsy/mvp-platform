3. Data layer and AI — every file in a category is read

Today the upload API keeps one active document per type and archives the previous one, and the diligence report receives one summary per type. This changes both: uploads never auto-archive, each file gets its own summary, and the report receives all summaries for a category (labelled by filename) so, for example, Financial review can cite the P&L and the balance sheet separately.
