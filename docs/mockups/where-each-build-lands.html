Three surfaces with no menu item

Public event page/events/[slug]
  • Auditorium before Talk Show, same rule as the email
  • “Who’s attending” chips, grouped Investors then Founders
  • Signed out: opted-in names plus a count. Signed in and registered: everyone
Registration form/events/[slug]/register
  • “List my name and badge on the event page”, default off
  • Shown to investors and founders only
  • Edited from Registration → Fields, not in code

  • Invitation to the investor, about the founder
  • Founder follow-up, capped at two
  • Accept page → lounge, talk now, book a time, or message
Event Brochure/admin/events/brochure
  • Inherits the session order automatically — same builder
  • No attendee list: a booklet is printed before anyone registers
  • Nothing else changes

Worth knowing

The per-event registrations board stays where it is. /admin/events/[id]/registrations is still linked from the event’s own More menu. The new page is the all-events view of the same rows — one list to search, one place to export.

Nothing lands in Analytics. Match and acceptance rates belong on the Networking page beside the rows they describe, not in a separate report you would have to remember to open.

One redirect to keep. /admin/events/registration-fields should redirect to the new tab rather than 404 — that URL is a year old and will be in someone’s bookmarks.
