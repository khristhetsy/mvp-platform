Admin workspace → Companies. What the search does today, and what it should do.

Why typing "a" looked like nothing happened

  1. It is filtering — you just can't tell. "a" matches almost every row through the founder's name (Martin, Tina, Charles, Alan…), so 23 rows stay on screen and nothing appears to move.
  2. The count never changes. countSub is passed count: companies.length — the unfiltered total. Filtered or not, it always reads "23 companies". This is the bug that makes search feel dead.
  3. No match is ever shown. Nothing is highlighted, there is no dropdown, no "6 of 23" — the only feedback is rows silently disappearing.
  4. It searches four fields only — company, industry, founder, review status. Typing Marketing, 78 or a founder's email finds nothing, even though those columns are on screen.
  5. Every other admin list uses OdooSearchBar with a typeahead dropdown. Companies is the one page still on a bare <input type="search">.
