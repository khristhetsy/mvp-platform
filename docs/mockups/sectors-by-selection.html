What it costs

One new stored field. optionsFrom: "sectors" stays, and an optional include: string[] of slugs joins it. Absent means all of them, so the current active version reg-fields-v1 needs no migration and behaves identically.

Untick ≠ delete. Turning off a sector stops it being offered from that moment. Registrations that already chose it keep their answer, in the database and in exports — same rule as removing a plain option today. The save dialog will say so.

The dead link goes. “Edit that list in its own settings” is removed rather than fixed: the 14 labels stay in code on purpose, because matching and event tracks read them too. This page chooses which are asked for, not what they’re called.
