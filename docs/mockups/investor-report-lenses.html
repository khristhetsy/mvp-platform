6. The rules this has to live inside

  • Never a recommendation. iCFO Capital Global is not a broker-dealer, funding portal, adviser or placement agent. Every panel reads as evidence and completeness. No ranking that implies endorsement, no “top pick”, no predicted outcome.
  • “Indicated interest”, never a commitment. The who-else-is-looking card shows counts, no names, no amounts.
  • No invented figures. Every number on every lens traces to a document, a stored score, or a count of real records. Where something is not there, the page says not found rather than estimating it.
  • Founders still cannot see their score. Nothing here changes that; the gap list is what reaches them, via the suggestions we already built.
  • One comparable number survives. Marketplace sorting keeps using the Series A column so lists stay apples-to-apples; the lens only changes this reader’s view of this company.

7. What exists, what is new

Already in load-company-report.ts

  • Overview, capital raise, use of funds
  • Readiness score + history (the velocity spark)
  • Document checklist + missingRequiredLabels (the completeness header)
  • Investor signals: views, interest, pledges, intros, meetings
  • Risk factors and public disclosures
  • Per-factor scores with sub-scores, evidence and flags
  • All four CRR columns, stored per company

New

  • The lens switch, and a default from the investor’s own type
  • A header that leads with completeness + trend instead of the score
  • Per-lens section ordering and which CRR column is shown
  • “Why you’re seeing this” — from the match record
  • “What to ask on the call” — the gap list, pointed at the investor instead of the founder
  • Cap table & governance pulled out as its own card for the family-office lens
  • Evidence provenance counts for the institutional lens
No migration. The heavy lifting is section ordering and choosing a column; the only genuinely new computation is counting evidenced vs. asserted claims, which reads the factor evidence already stored.
