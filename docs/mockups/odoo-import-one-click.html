What happens automatically

IR projectOne per founder, named after the founder's company. Term = number of Odoo months (min 4). Start date = earliest task date. Owner = the Odoo project owner. Founder linkMatched to the Sales Hub founder contact / company by name. If none exists, a founder contact is created (name + company from Odoo). Months and weeks"Month 2" in the project name → month 2; "2nd Week" in the task name → week 2. Tasks with no week go to week 1 of their month. InvestorsRead from the Matches, Contact and Meetings fields on each task. Matched to Investor Contacts by email, then name + firm, then name. Field name sets the stage (Matches → Matched, Contact → Contacted, Meetings → Meeting scheduled). ActivitiesAgent Field text parsed into dated emails / calls / meetings; stage history backdated so past-week reports are right. Re-runningSafe any time. Adds only what is missing; never duplicates, never changes Odoo.
