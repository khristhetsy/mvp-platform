The small grey number in each card header is that dimension’s weight for that company’s own stage profile — so a pre-seed company shows Narrative 30 / Team 30, a Series A company shows Traction 30 / Financial 25. It answers “does this weak score actually matter here?” without opening anything.

3. Where the suggestion text comes from — the one real decision here

“AI suggestion for improvement” does not exist yet. What exists is per-factor aiSummary text and flags with a detail field that already reads like advice (“Upload financial statements even for pre-revenue stage”). Three ways to fill the panel, cheapest first.

SourceCostWhat you get
1 · Assemble from flags
no AI call
 free, instant, works offline Rank the existing red/amber flags inside the dimension by points lost, print them as the list. Honest and specific, but the wording is the generic flag text — it does not mention what this company’s documents actually said.
2 · One Claude call per dimension
on open, cached
 ~1 call per card opened · cached on the score row so re-opening is free What’s drawn above. Reads the factor evidence and sub-scores and writes three ranked actions in the company’s own terms. Regenerates only when the score is re-run.
3 · Generate all five at scoring time
baked into the run
 5 extra calls per company per re-score · 22 companies = 110 Instant to open, and the text is part of the stored score so it can go into founder reports and the outreach email. Most expensive, and it pays for suggestions nobody opens.
Recommended: 2, with 1 as the fallback. Generate on open and cache it on the score row, so the second look is instant and a re-score clears it. If ANTHROPIC_API_KEY is missing or the call fails, fall back to the assembled flags rather than showing an empty panel — the same graceful-degradation rule the rest of the AI features follow.
The point gains are arithmetic, not AI. “+3.8 to the score” is computed: sub-score headroom × factor weight × dimension weight for that company’s profile. Claude writes the sentence; the number never comes from Claude, because a made-up number here would be worse than no number.

What this costs

Already there

  • rollupToDimensions — the five scores are computed today, just never displayed.
  • The factor popup, with sub-scores, evidence and flags.
  • The per-stage weights, so the small grey number and the “contributes now” maths are a lookup.

New

  • The five cards in the column, and the panel.
  • The headroom arithmetic (“if it hit 60”) — pure, testable, no AI.
  • The suggestion call + a cache column on company_readiness_scores, which means a migration.
  • “Send to founder” — decide whether that goes now or later; everything else works without it.
