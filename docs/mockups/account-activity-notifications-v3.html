Quiet hours, pause all and critical override already exist at /admin/sales/settings/notifications and apply here unchanged. This adds folded blocks to that page rather than a second settings screen.

Slack is still dead. channel_slack is declared in NotificationPrefs and nothing reads it. It is deliberately not shown as a channel above — a control that cannot run should not be rendered.
Investors don't have the founder's four stages, and forcing them into it would lie. They have INVESTOR_PIPELINE_STAGES — prospect, outreach, engaged, diligence, committed — already in the code and already on the pipeline board. So the audience toggle swaps the fold axis rather than filtering the same four folds, and a fold means the same thing in the feed as it does on the board.

Type search is a facet, not free text. Typing matches company / actor / entity as it always has; the dropdown adds an Activity type group with a live count beside each, and picking one adds a removable chip. Two chips are ANDed with the typed text, so Document replaced + Document deleted + “tinski” reads as one sentence — which is the pattern OdooSearchBar already uses everywhere else.

The date range needs an index. Six presets plus custom over a table that will grow faster than any other on the platform means operational_activity_events (created_at desc) — and, given the folds, a composite on (stage, created_at desc). Worth deciding before the first emitter ships, not after.

Still open. Whether events store the old value ($750,000 → $400,000) or only the field name.
