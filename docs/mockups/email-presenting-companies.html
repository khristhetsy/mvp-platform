Worth knowing

headline is a topic field, not a company name. On your roster most rows already hold the company — SOHM, Harvard MedTech, Amynas — but one reads “ClearPool Digital (cplx.oi)”, which is a talk title with a ticker in it. The block prints what’s on the roster; it can’t know which is which. Tidy the topic field and the email tidies with it.

Order is arbitrary. Presenters sort by position and nothing in the codebase ever sets it, so every row sits at 0 and the list comes out in whatever order the database returns — the same limitation the booklet has. Alphabetical by company would be a defensible default here; say if you’d rather have that than roster order.

Invited ≠ presenting. Only accepted invitations create a roster row, so anyone still sitting at “invited” won’t appear. That’s correct for an email going to attendees, but it’s worth knowing before you send.
