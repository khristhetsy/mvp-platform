The labels move to the table header, so they are written once instead of 22 times, and every company’s numbers line up in the same column. E. Grouped into the five dimensions the weights actually use

The 13 factors already roll up into 5 dimensions — Narrative, Team, Financial, Traction, Cap table — and those five are what the Weights tab edits. This column shows the rollup, so the Companies tab and the Weights tab finally speak the same language. Click a dimension to open the factors inside it.
