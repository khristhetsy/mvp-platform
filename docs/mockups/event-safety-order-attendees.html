Name and badge only — no company, no email, no title. Same block on the event page and in the email, where it sits under Presenting companies as plain text rows rather than chips. Service providers and sponsors aren’t shown; they register for different reasons.

This publishes attendee names, and nobody agreed to that. The registration form asks for name, email, firm and thesis to attend — it never says the name will appear on a public page that Google can index. Adding the list without asking changes what those 41 people consented to.

Two ways to do it honestly. Either add a tick to the registration form — “List my name on the event page”, default off, and show only those who said yes; or show the list only to people who are themselves registered and signed in, which is what most event platforms do. The first is more visible, the second needs no new consent for anyone already registered. I’d do both: opt-in for the public page, everyone for the signed-in view.

Sessions don’t move with the event. Each session carries its own starts_at, so changing the event date leaves all four sessions on the old day. The dialog says so; it does not move them silently. Offering “shift sessions by the same amount” as a tick in that dialog would be the obvious follow-up — say if you want it.

A published booklet freezes its data. The PDF is generated from a snapshot, so the old date stays printed until it is regenerated. The dialog counts it; it can’t fix it.
